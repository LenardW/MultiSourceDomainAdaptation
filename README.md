Domain Adaptation is an area that deals with transfering knowledge from a trained model to a new related situation, which differs particularly in the input representation of the data.
In this medical setting, we are interested in predicting a specific heart signal (regression) for a new individual, based only on ground truth recordings of several other ones.
This challenging problem is referd to as Multiple Source Domain Adaptation, and promising algorithms do exist (often inspired by their single source domain adaptation variants).
The task involves selecting a (few) promosing algorithm(s) out of a rather large corpus on developed methods for this task, potentially adapt it to the regssion setting (since
literature mostly deals with classification problems) and in a first step investigate how well the problem can be solved. The second step then involves using explainable AI
methodology to get insights into the workings of the model, such as most important features (including interactions) or source domains.
